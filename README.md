# Categories-

Инструменты для работы с товарными категориями и вспомогательные утилиты.

## Partner Email Parser

Парсер email-адресов с сайтов партнёров — см. [`email_parser/README.md`](email_parser/README.md).

```bash
pip install -r email_parser/requirements.txt
PYTHONPATH=. python3 -m email_parser -u https://partner.ru -o report.json --csv report.csv
```
